# SPORTSCENTRAL — individual sports updates project

SPORTSCENTRAL is an individual sports dashboard built from the Trailblazer starter repository. It presents sample sports headlines across Football, Basketball, Formula 1 and Athletics, with category filters.

## Run locally

1. Open this folder in VS Code.
2. In the terminal run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000`.

## Project files

- `index.html` — page structure and navigation.
- `style.css` — responsive dark sports-desk design.
- `app.js` — renders update cards and handles category filters.
- `src/service.js` — loads and validates sports update data.
- `data/sports-updates.json` — sample content for the dashboard.

## Important data note

The updates in `data/sports-updates.json` are made up for this course. They are not live news, fixtures or real match results. A live sports data source can be integrated in a later iteration after its terms, reliability and privacy implications are reviewed.

## Checks

Run `npm test` to run the starter repository's automated tests. The original practice pages, challenge data, documentation templates, and checks are retained.
